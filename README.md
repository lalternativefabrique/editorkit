# editorkit

`@lalternative/editor`: a shared TipTap editor for React and React Native, with rich text, a format menu, a selection toolbar, slash commands, dictation and inline AI revisions.

```sh
pnpm add @lalternative/editor @tiptap/core @tiptap/pm @tiptap/react @tiptap/starter-kit @tiptap/suggestion
```

| Entry point | Content |
| --- | --- |
| `@lalternative/editor` | Web editor and its React hooks |
| `@lalternative/editor/revisions` | Inline AI revision state, framework-free |
| `@lalternative/editor/native` | React Native toolbar and format sheet |
| `@lalternative/editor/styles.css` | Editor styles |

`pnpm playground` starts a local playground.
